What changed between the trials

The duration did not change. Only the interface did.

Progress
Trial A hides elapsed time. Trial B makes progress visible.
Rhythm
Trial A repeats one static message. Trial B changes its prompt as time passes.
Expectation
Trial A leaves the ending uncertain. Trial B shows how close the ending is.
